01　数据导入

每批可上传一份含样品、浓度、读数的长表，或上传原始信号 + 设计表。支持 CSV / TSV / TXT / XLSX / JSON；请显式确认单位与高低信号对照。
high=高信号对照，low=低信号对照，各至少2条。激活实验需把最大响应标high、基础信号标low；样品浓度以所选单位换算成nM。质量浓度、图片/PDF数值提取、动力学与混合多块板尚不支持。
默认阈值用于演示。参考药效内控须由实验人员指定；未指定时不能声称该项检查通过。观测/预期效价的0.5–2倍为演示区间。保留所有复孔；使用终浓度nM，不用3倍工作液浓度。
